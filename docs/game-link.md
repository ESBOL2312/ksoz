# Связка с игрой «Ер Төстік»

Игра получает код из 6 цифр, игрок подтверждает его в боте (или в миниаппе), игра забирает
токен только для чтения и с ним читает купленные в базаре вещи. Покупать и тратить алтын
с токеном игры нельзя.

## Порядок

1. Игра один раз создаёт `device_id` (UUID, 16–64 символа `A-Z a-z 0-9 -`) и хранит его в сохранении.
2. `POST /v1/game/link-codes` `{ "device_id": "…" }` →
   `{ "code": "482913", "expires_at": "…", "bot_url": "https://t.me/<бот>?start=link_482913" }`.
   Код живёт 10 минут; новый код для того же устройства отменяет прежний неподтверждённый.
3. Игра показывает код и кнопку «Открыть бота» (`bot_url`). В боте можно ввести код вручную: `/link 482913`.
   Бот спрашивает «Подключить игру «Ер Төстік»?», кнопка «Да» подтверждает код
   (пользователь kSoz создаётся, если он ещё не открывал миниапп).
4. Игра раз в 3 секунды спрашивает `GET /v1/game/link-codes/482913?device_id=…`:
   - `{ "status": "pending", "expires_at": "…" }` — ждём;
   - `{ "status": "expired" }` — просим новый код;
   - `{ "status": "confirmed", "token": "…", "first_name": "…" }` — токен отдаётся **один раз**;
   - `404 code_not_found` — кода нет или он выдан другому `device_id`;
   - `409 code_already_claimed` — токен по этому коду уже забрали.
   Подтверждённый код можно забрать ещё 5 минут после истечения.
5. Дальше `GET /v1/game/inventory` с `Authorization: Game <токен>` →

   ```json
   {
     "first_name": "Айгерім",
     "altyn": 240,
     "items": [
       { "id": 1, "key": "chapan", "kk": "Шапан", "ru": "Чапан", "category": "kiim",
         "slot": "body", "image_url": null, "equipped": true, "set": null, "rarity": null }
     ]
   }
   ```

   `key` — стабильный ключ рисунка (тот же, что у миниаппа без `image_url`): `yurt`, `dombra`,
   `chapan`, `syrmak`, `eagle`, `horse`, `takiya`, `etik`, `cat`, `sheep`, `tea`.
   `set` и `rarity` пока всегда `null`, появятся вместе с сетами Төстіка.
6. `DELETE /v1/game/link` тем же токеном отвязывает устройство. Ответ `401` на любом методе
   с токеном значит, что связку отозвали (в игре или в профиле миниаппа): стираем токен и вещи.

Одно устройство связано с одним аккаунтом: новая связка того же `device_id` заменяет старую.

## Методы миниаппа (`Authorization: tma …`)

- `POST /v1/game/link-codes/:code/confirm` — подтвердить код (не больше 5 в минуту).
- `GET /v1/game/links` → `{ "links": [{ "id", "created_at", "last_seen_at" }] }` — подключённые устройства.
- `DELETE /v1/game/links/:id` — отвязать устройство.

## Лимиты

| Метод | Лимит |
|---|---|
| `POST /v1/game/link-codes` | 20 в минуту на IP |
| `GET /v1/game/link-codes/:code` | 40 в минуту на `device_id` |
| `GET /v1/game/inventory` | 30 в минуту на токен |
| `DELETE /v1/game/link` | 10 в минуту на токен |
| бот `/link`, `/start link_…` | 5 попыток в минуту на игрока |

Лимиты хранятся в памяти процесса и сбрасываются при деплое.

## CORS

Веб-сборке нужен свой origin в `GAME_ORIGINS` (через запятую; `*` заменяет одну метку домена
без точек, например `https://yer-tostik-*.vercel.app`). Он действует только для `/v1/game/*`,
CORS миниаппа (`WEB_ORIGIN`) не меняется. Android-сборке CORS не нужен.
